# 굿즈 메이커 v22

브라우저에서 아크릴·코롯토·스티커 제작용 칼선과 출력 레이어를 만들고, 외곽선·배경 이미지를 편집하는 굿즈 제작용 정적 웹 앱입니다. 별도 서버 없이 `index.html`, `style.css`, `app.js`만으로 실행됩니다.

## v20 주요 변경 사항

### 합친 칼선의 묶음 이동과 내부 개체 편집

- 칼선을 합친 뒤에는 포함된 개체가 **하나의 묶음으로 선택되고 함께 이동**합니다.
- 합친 칼선을 한 번 클릭하면 묶음 전체를 선택합니다.
- 묶음 안의 개체를 더블클릭하면 해당 개체만 따로 선택해 이동할 수 있습니다.
- 개별 편집 상태에서 다른 내부 개체를 더블클릭하면 두 개 이상을 함께 선택해 같이 이동할 수 있습니다.
- 개별 선택된 개체를 움직이지 않고 한 번 클릭하거나, 대지의 빈 곳을 클릭하면 개별 선택이 해제됩니다.
- 모바일에서는 같은 개체를 빠르게 두 번 탭해 개별 편집을 켜거나 끕니다.

### 클릭·드래그 선택과 칼선 합치기

- 쪼개기 미리보기 칼선을 **클릭으로 하나씩 추가 선택**할 수 있도록 선택 판정을 보완했습니다.
- 빈 영역에서 드래그해 여러 미리보기 칼선을 한꺼번에 선택할 수도 있습니다.
- threshold보다 멀리 떨어진 개체도 직접 선택한 뒤 `선택 칼선 합치기`로 묶을 수 있습니다.
- 쪼개기에서 만들어진 개체뿐 아니라, 이미 대지에 놓인 **서로 다른 업로드 이미지와 기존 합치기 묶음**도 다시 합칠 수 있습니다.
- 이미지가 겹치는 경우 `현재 순서 유지 / 마지막 선택을 맨 위 / 첫 선택을 맨 위` 중 하나를 선택할 수 있습니다.
- 합치기 해제를 누르면 각 개체를 다시 독립적으로 편집할 수 있습니다.

### 스티커 여백 자동 배치

- `칼선 사이 최소 간격`을 mm 단위로 입력하거나 포커스 슬라이더로 조절할 수 있습니다.
- `여백 자동 배치`를 누르면 각 칼선 사이가 설정값 이상 떨어지도록 겹친 부분을 풀어냅니다.
- 이미 충분히 떨어진 개체는 움직이지 않고, 필요한 개체만 양쪽으로 나눠 이동해 전체 이동량을 줄입니다.
- 합친 칼선은 내부 간격과 배치를 유지한 채 하나의 묶음으로 이동합니다.
- 대지가 좁아 간격을 모두 확보할 수 없으면 경고를 표시합니다.

### 패턴 입자 회전

스티커 배경과 외곽선/배경 메이커의 입자 패턴에 다음 회전 설정을 제공합니다.

- 모든 입자에 같은 회전 각도 적용
- 최소·최대 각도 사이에서 안정적인 랜덤 회전
- 업로드 이미지, 별, 하트 등 입자형 패턴에 적용
- 여러 업로드 이미지의 균형 순환 또는 자연스러운 랜덤 순서와 함께 사용 가능

### 배경 이미지 회전

- 스티커 배경 이미지와 메이커 배경 이미지에 원하는 회전 각도를 직접 입력할 수 있습니다.
- 왼쪽·오른쪽 90° 회전 버튼을 제공합니다.
- `채우기`, `전체 보이기`, `늘이기`, `직접 설정` 배치에서도 회전된 이미지의 외곽 크기를 고려합니다.

### 모든 탭 실행취소·재실행

- 상단의 `실행취소`와 `재실행` 버튼을 아크릴/코롯토, 스티커, 외곽선/배경 탭에서 공통으로 사용할 수 있습니다.
- 이미지 위치·크기·회전, 칼선 합치기, 자동 배치, 타공, 배경과 패턴, 효과와 수치 설정을 되돌릴 수 있습니다.
- 최대 45단계의 작업 기록을 유지합니다.
- 단축키:
  - 실행취소: `Ctrl/Cmd + Z`
  - 재실행: `Ctrl/Cmd + Shift + Z` 또는 `Ctrl + Y`

## 기존 주요 기능

### 스티커 개체 쪼개기

- **0 mm에서는 원본 이미지의 알파 픽셀 기준으로 완전히 떨어진 개체를 모두 분리**합니다.
- 연결 거리(threshold)는 칼선 여백이 아니라 원본 개체 픽셀 사이의 실제 거리를 기준으로 계산합니다.
- threshold 안의 개체는 곡선 연결부를 가진 하나의 미리보기 칼선으로 자동 묶입니다.
- `미리보기 적용 · 칼선 새로고침`을 누르면 각 미리보기 개체가 독립 이미지로 바뀌어 이동·회전·크기 조절할 수 있습니다.

### 정렬과 직접 편집

- 가로 중앙, 세로 중앙, 전체 중앙 정렬
- 칼선 기준 위·아래·왼쪽·오른쪽 정렬
- 여러 개체 선택 시 현재 간격을 유지한 묶음 정렬
- 모바일과 데스크톱에서 이동, 비율 유지 크기 조절, 회전 지원
- 숫자 입력창에 포커스할 때만 아래 슬라이더가 나타나며 숫자와 양방향으로 동기화

### 패턴 배경

- 사각 그리드, 사선 그리드, 땡땡이, 줄무늬, 별, 하트, 업로드 이미지 패턴
- 그리드·줄무늬의 실선/점선과 선 굵기
- 입자 패턴의 크기, 간격, 사각·사선·랜덤 배치
- 패턴 배경을 단색 또는 그라데이션으로 설정
- 여러 패턴 이미지 동시 업로드 및 투명 여백 자동 제거
- 이미지 개수와 서로소인 행 이동값을 이용하는 겹침 방지 균형 순환
- 홀수 개 이미지에도 적용되는 자연스러운 랜덤 이미지 순서

### 컬러피커

- 채도·밝기 2차원 선택 영역
- 실제 이동할 색이 보이는 무지개 Hue 바
- 현재 색의 투명 변화를 보여 주는 알파 바
- 흰색 원형 슬라이더 손잡이
- 8자리 HEX와 투명도 지원

### 외곽선 / 배경 메이커

이 탭은 제작용 칼선·화이트 추출 없이 일반 이미지를 만드는 편집기입니다.

- 업로드 이미지의 투명 여백 자동 제거
- 이동, 회전, 크기 변경, 앞뒤 순서 조절
- 외곽선, 외부광선, 내부광선, 그림자 효과
- 선택 개체의 효과 설정을 모든 개체에 일괄 적용
- 곡선 보간과 안티에일리어싱을 적용한 외곽선
- 투명·단색·그라데이션·이미지·패턴 배경
- PNG와 JPG 저장
- PNG 저장 시 투명 배경 또는 흰 배경 선택

### 내보내기 파일 이름

상단의 `파일 이름` 입력란에 원하는 이름을 입력하면 해당 이름으로 저장됩니다. 비워 두면 모드에 맞는 기본 이름을 사용하며 확장자는 자동으로 붙습니다.

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열 수 있습니다. 브라우저의 로컬 파일 보안 정책으로 작업 저장 복원이 제한되면 GitHub Pages 같은 정적 호스팅에 올려 사용하세요.

## GitHub Pages 배포

1. 저장소 최상위에 다음 파일을 업로드합니다.

   ```text
   index.html
   style.css
   app.js
   README.md
   ```

2. `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.
5. 배포가 완료되면 Pages 화면의 `Visit site`에서 주소를 확인합니다.

기존 저장소를 업데이트할 때는 네 파일을 모두 덮어써야 합니다. 이전 코드가 남아 보이면 강력 새로고침을 사용하세요.

- Windows: `Ctrl + Shift + R`
- macOS: `Command + Shift + R`

## 작업 저장

편집 중인 이미지와 설정은 같은 브라우저·같은 배포 주소의 IndexedDB에 저장됩니다. 새로고침 후에도 복원되며 `초기화`를 누르면 현재 모드의 작업이 비워집니다. 시크릿 모드, 브라우저 데이터 삭제, 배포 도메인 변경 시 저장 내용이 사라질 수 있습니다.

실행취소·재실행 기록은 현재 페이지 세션의 메모리에 보관됩니다. 페이지를 새로고침하면 작업 자체는 복원되지만 실행취소 기록은 새로 시작합니다.

## 출력 형식

- 아크릴/코롯토·스티커: 선택 레이어 PNG, SVG, PDF 1.4 호환 `.ai`
- 외곽선/배경 메이커: PNG, JPG

`.ai`는 Adobe Illustrator의 비공개 네이티브 구조가 아니라 Illustrator에서 열 수 있는 PDF 호환 파일입니다. 실제 발주 전 제작 업체의 별색, 오버프린트, CMYK, 타공 규격을 확인하세요.

## v21 · 이미지 작업 그룹화

- 외곽선/배경 메이커에 다중 선택 모드를 추가했습니다.
- 다중 선택을 켜고 개체를 차례로 클릭하거나 빈 대지에서 드래그하면 여러 개체가 선택됩니다.
- 여러 개체가 선택된 상태에서는 함께 이동할 수 있습니다.
- `선택 개체 그룹화`를 누르면 겹친 이미지를 하나의 합성 이미지로 인식합니다.
- 그룹 외곽선, 외부광선, 내부광선, 그림자는 개별 이미지 경계가 아니라 그룹 전체 알파 영역을 기준으로 한 번만 적용됩니다.
- 그룹 안에서 이미지가 겹치는 부분에는 외곽선이 끼어들지 않습니다.
- 그룹은 앞뒤 순서를 유지한 하나의 레이어 묶음으로 이동하며, 그룹 해제로 다시 개별 개체로 돌릴 수 있습니다.
- 그룹 정보, 다중 선택 상태는 새로고침 복원과 실행취소/재실행에 포함됩니다.
## v22 패턴 파티클 확장

- 기본 파티클에 `사각별`과 길고 짧은 꼭짓점이 교차하는 `팔각별`을 추가했습니다.
- 스티커 배경과 이미지 작업 배경 모두 입자 크기를 고정값 또는 최소·최대 범위의 랜덤값으로 만들 수 있습니다.
- 위치 랜덤을 켜면 `분산`으로 각 배열 칸 안에서 흩어지는 정도를, `밀도`로 전체 입자 수를 조절할 수 있습니다.
- 랜덤 결과는 같은 설정에서 계속 흔들리지 않도록 좌표 기반 고정 난수를 사용합니다.
- 그리드·사선 그리드·줄무늬는 기존처럼 선 패턴으로 유지되며, 랜덤 크기·위치 옵션은 이미지와 도형 파티클에만 표시됩니다.
