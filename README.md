# 아크릴 제작 매니저 👾

투명 이미지를 브라우저에서 분석해 코롯토·아크릴과 스티커 대지용 **그림 / 화이트 / 재단여백 확장 / 칼선** 레이어를 만드는 정적 웹 앱입니다. 서버에 이미지를 전송하지 않고 현재 브라우저에서 계산하며, GitHub Pages 또는 Railway의 정적 사이트로 배포할 수 있습니다.


### 이번 수정

- **이미지를 선택해도 대지와 사진이 보이지 않던 상황을 방어적으로 수정**
  - 생성 결과가 아직 없어도 입력한 대지 크기를 먼저 표시
  - 이미지를 읽은 직후 원본을 대지에 임시 표시하고, 그 뒤 칼선과 확장 도안을 계산
  - 파일 읽기·저장 작업 복원 오류가 나도 화면 전체가 멈추지 않도록 예외 처리
  - 같은 파일을 다시 선택할 수 있도록 파일 입력값 자동 초기화
  - GitHub Pages에서 이전 `app.js`·`style.css` 캐시가 남지 않도록 배포 파일에 버전 쿼리 적용
- **그림 크기와 확대율 양방향 연동**
  - 그림 가로·세로를 입력하면 300 ppi 기준 원본 크기 대비 확대율을 자동 계산
  - 확대율을 입력하면 그림 가로·세로를 자동 계산
  - 확대율 입력 시 원본 비율 유지가 자동 적용됨
- **확장 도안 가장자리 안티에일리어싱**
  - 확장색 바깥쪽에 색상 기반 1 px 서브픽셀 알파를 생성해 계단 모양 완화
  - 타공 고리처럼 투명도를 보호해야 하는 영역에는 안티에일리어싱 색이 번지지 않음
- **단색·그라데이션 혼합 도안의 색상 확장 개선**
  - 넓고 안정적인 단색 덩어리를 내부에서 먼저 판정한 뒤 경계까지 연결
  - JPEG/WebP의 미세한 압축 노이즈가 있어도 실제 단색 면이면 대표색 한 가지로 고정
  - 일정 방향으로 색이 변하는 영역은 단색으로 오인하지 않고 기존 그라데이션 평면 확장 유지
  - 단색과 그라데이션이 맞닿는 경계에서는 각 영역의 확장 방식을 따로 유지

## 이번 버전의 핵심 기능

### 코롯토 / 아크릴

- `대지 크기`: 체크무늬 작업 영역과 PNG·SVG·AI 출력 파일의 실제 가로·세로 크기
- `그림 크기`: 대지 중앙에 배치되는 원본 도안의 크기. 비율 유지 여부를 선택하고 대지 안에 자동 맞출 수 있음
- `원본 크기 대비 확대율`: 원본 픽셀을 300 ppi로 출력한 크기를 100%로 사용하며, 가로·세로와 확대율이 양방향으로 연동됨
- 그림, 재단여백, 외부 타공이 대지 끝에 닿으면 잘림 경고 표시
- `무테`: 그림 외곽을 칼선으로 사용하고, 인접 색을 바깥쪽으로 연속 확장해 재단여백 생성
- `유테`: 입력한 투명 테두리 폭만큼 떨어진 외곽에 칼선 생성
- 내부 빈 공간의 별도 칼선 포함 여부 선택
  - 끄면 내부 구멍에는 칼선도, 색상 확장도 생성하지 않음
- 끝의 안티에일리어싱 한 픽셀이 아니라 경계 안쪽 여러 픽셀·접선·법선·색상 영역을 함께 분석
- 넓은 단색 면은 대표색 하나로 확장하고, 그라데이션 영역은 경계 근처 색 변화면을 추정해 흐름을 유지
- 확장 도안 바깥쪽에 색상 기반 안티에일리어싱을 적용해 미리보기와 래스터 출력의 계단 현상 완화
- 만들어진 확장색을 그림 안쪽으로 2 px 겹쳐 깐 뒤 원본을 다시 올려, 원본과 확장 도안 사이에 투명 실선이 남는 현상 방지

### 밑바닥

- 밑바닥과 도안 사이를 `빈 공간 유지 / 색상 채우기` 중 선택
- 무테
  - 이미지 좌우 절반에서 각각 가장 아래로 돌출된 안정적인 픽셀 영역을 찾아 연결
  - 연결선 양옆으로 불필요한 투명 픽셀이 튀어나오지 않도록 밑바닥 추가 마스크 제한
  - 두 돌출부 높이가 다르면 `두 돌출부 연결 / 이미지 잘라 수평` 선택
  - 수평 보정 시 추가 올림 값을 mm로 입력해 아래 이미지를 더 잘라낼 수 있음
- 유테
  - 최하단 주변과 색이 엄격하게 비슷한 연결 픽셀 덩어리의 좌우 끝을 기준으로 둥근 사각 받침 생성
  - 또는 이미지 전체 좌우 끝 기준으로 받침 생성
  - 받침 밑면은 수평이며, 가장 낮은 이미지 지점 아래로 설정한 테두리 폭만큼 내려감
- `밑바닥 모서리 둥글기` 슬라이더는 밑바닥 양쪽 모서리와 도안 접합부에만 적용되며, 캐릭터·타공 등 나머지 칼선 외곽은 변경하지 않음

### 타공

- 내부·외부 타공을 한 개씩 추가해 여러 개를 동시에 배치 가능
- 완성된 타공이나 목록 항목을 클릭하면 수정 가이드가 켜지고, 다시 클릭하면 꺼짐
- 여러 타공을 차례로 클릭해 동시에 가이드를 표시할 수 있으며 마지막으로 선택한 타공이 수치 편집 대상이 됨
- 가이드를 드래그해 위치를 잡은 뒤 `칼선 다시 만들기`를 눌렀을 때만 최종 연산
- 다시 만들기가 끝나면 수정 가이드는 자동으로 닫히지만 타공 자체는 삭제되지 않으며, 직접 삭제하기 전까지 새로고침 후에도 유지
- 내부 타공
  - 원본 그림과 화이트는 그대로 유지
  - 인쇄 이미지에 투명 구멍을 뚫지 않고 칼선 레이어에만 원형 구멍 패스 추가
  - 칼선에서 기본 2.5 mm 안쪽에 배치하며, 입력한 안전거리 안에서 이동
- 외부 타공
  - 기본 직경 3 mm, 투명 고리 벽 두께 1.5 mm
  - 아래쪽이 기존 아크릴 외곽에 묻히도록 결합하고 접합부를 둥글게 정리
  - 고리와 그림이 겹치는 부분은 그림 픽셀을 우선하고, 그 밖의 고리·구멍은 투명 픽셀로 취급
  - 무테 색상 확장 시 투명 픽셀도 바깥으로 함께 전파해 고리 둘레에 확장색 테두리가 생기지 않도록 차단
- 직경, 외부 고리 두께, 내부 타공과 칼선 사이 거리는 각 타공마다 직접 수정 가능

타공 규격은 제작소마다 다릅니다. 앱의 값은 편집 가능한 시작값이며, 실제 주문 전 제작소 템플릿과 최소 두께 규격을 우선하세요.

### 칼선 품질

- 칼선에 붙은 작은 픽셀과 짧은 가시는 물리 크기와 연결 폭을 함께 확인해 제거하며, 실제로 길거나 넓은 돌출부는 유지
- 유테의 좁은 홈은 칼선 사이 간격이 4 mm 이하일 때 외부와 연결된 입구만 자동으로 메워 깊숙한 U자 칼선이 생기지 않게 처리
- 단, `빈 공간 유지`로 만든 밑받침 위의 투명 통로는 의도된 공간이므로 좁은 홈 자동 연결 대상에서 제외
- 유클리드 거리 기반 원형 오프셋으로 여백과 외곽의 모서리를 자연스럽게 둥글림
- 사용자용 `단순화 / 부드럽게` 조절 기능은 제거
- 알파 임계값과 픽셀 격자에서 생기는 1~2 px 요철을 mm 기준 저역 통과 필터로 제거하고, 면적을 다시 맞춰 외곽이 안쪽으로 줄어드는 현상을 억제
- 곡선을 일정한 호 길이 간격으로 다시 표본화한 뒤 cubic Bézier로 연결해 긴 원호가 짧은 다각형이나 찌글찌글한 선으로 보이지 않게 처리
- 미리보기와 PNG·SVG·AI 출력에 같은 곡선 데이터를 사용

### 스티커 대지

- 여러 투명 이미지 추가, 드래그 이동, 회전, 크기 변경, 앞뒤 순서 변경
- 무테: 배치된 각 이미지에 색상 재단여백과 칼선 생성
- 유테: 입력한 폭만큼 떨어진 칼선 생성
  - 칼선 안쪽을 `투명 / 화이트`로 선택
  - 화이트 선택 시 칼선 밖에도 별도 화이트 재단여백 추가
- 배경지
  - 단색
  - 배경 이미지: 대지 채우기 / 전체 보이기 / 늘이기 / 직접 설정
  - 직접 설정: 확대율, 가로 위치, 세로 위치
  - 반복 패턴: 상하좌우 타일 반복, 확대율과 가로·세로 위치 조정
- 배경지는 별도 레이어로 미리보기·출력 가능


### 화이트 분리 출력

반투명 픽셀을 포함한 이미지도 제작 방식에 맞게 선택할 수 있도록 화이트를 두 레이어로 생성합니다.

- `화이트 · 실제 반투명 면 제외`: 외곽의 얇은 안티에일리어싱 띠는 제외하지 않고 화이트를 유지하며, 일정 면적과 내부 두께가 있는 실제 반투명 영역 아래에서만 화이트를 뺌
- `화이트 · 전체`: 실제 반투명 면과 안티에일리어싱을 포함한 인쇄 영역 전체에 화이트 생성
- 실제 반투명 판정은 연결 면적, 가로·세로 두께, 침식 후 남는 내부 핵심 영역을 함께 확인하므로 1~몇 픽셀짜리 외곽 안티에일리어싱만으로는 반투명 면으로 처리하지 않음
- 스티커가 겹친 경우 위쪽 이미지의 실제 반투명 면 아래에 남아 있던 아래쪽 스티커 화이트도 제거
- 미리보기 탭과 PNG·SVG·AI 다운로드 체크박스에서 두 레이어를 각각 선택 가능

## 작업 자동 보존

- 업로드한 아크릴 원본, 스티커 이미지, 배경 이미지·패턴과 주요 편집값을 브라우저의 IndexedDB에 자동 저장합니다.
- 새로고침하거나 같은 브라우저에서 페이지를 다시 열면 마지막 작업을 불러와 칼선과 레이어를 다시 계산합니다.
- 이미지 저장소를 사용할 수 없는 환경에서도 크기·여백·모드 같은 설정값은 가능한 범위에서 복원합니다.
- 상단 `초기화` 버튼을 누르면 현재 탭의 작업을 비우고, 비워진 상태가 다음 새로고침에도 유지됩니다.
- 저장 내용은 서버로 전송되지 않으며 현재 브라우저 프로필 안에만 남습니다. 사이트 데이터나 브라우저 저장 공간을 삭제하면 함께 사라집니다.

## 화면 디자인

- 전체 UI를 채도가 낮은 하늘색 계열로 조정했습니다.
- 실제 투명 영역을 확인하는 작업 대지의 체크무늬는 색 판단에 영향을 덜 주도록 중립 회색으로 유지합니다.
- 코롯토·아크릴 입력 영역의 단계 표시는 스티커 대지와 같은 형식의 `ACRYLIC MODE`로 표시합니다.

## 미리보기와 내보내기

미리보기에서 다음 레이어를 개별로 켜거나 끌 수 있습니다.

- 배경지
- 그림
- 화이트 · 실제 반투명 면 제외
- 화이트 · 전체
- 재단여백 확장 도안
- 칼선

다운로드 체크박스로 포함할 레이어를 선택한 뒤 다음 형식으로 저장합니다.

- **PNG**: 선택한 레이어만 투명 PNG 한 장으로 합성
- **SVG**: `BACKGROUND`, `WHITE_OPAQUE_ONLY`, `WHITE_FULL`, `BLEED_EXTENSION`, `ARTWORK`, `CUTLINE` 그룹
- **AI**: Illustrator에서 열 수 있는 PDF 1.4 호환 `.ai`; 두 화이트 래스터 레이어, 투명 인쇄층과 벡터 칼선 포함

AI 파일은 Adobe의 비공개 네이티브 AI 구조가 아닙니다. 실제 제작 전 Illustrator에서 칼선 별색, 선 굵기, 오버프린트, CMYK, 화이트 인쇄 설정을 확인하세요.

## 실행

다음 네 파일을 같은 폴더에 둡니다.

```text
index.html
style.css
app.js
README.md
```

`index.html`을 브라우저에서 열면 됩니다. 로컬 파일 정책으로 이미지 처리가 막히는 브라우저에서는 폴더에서 다음을 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## Railway 배포와 속도

이 앱의 색상 확장·거리 변환·벡터화 계산은 서버가 아니라 사용자의 브라우저에서 실행됩니다. 따라서 GitHub Pages에서 Railway로 정적 배포 위치만 옮겨도 계산 시간은 거의 달라지지 않습니다. Railway를 사용한다면 정적 파일을 서비스하는 용도로 배포하면 됩니다.

속도가 느릴 때는 다음 순서가 효율적입니다.

1. 배치와 옵션을 정할 때 `빠른 편집`
2. 타공 위치는 드래그만 하고 계산하지 않음
3. 최종 위치를 정한 뒤 `다시 만들기`
4. 내보내기 직전에 `균형` 또는 `정밀 출력`

큰 원본 여러 장, 넓은 재단여백, 정밀 출력은 브라우저 메모리와 CPU 사용량이 증가합니다.
