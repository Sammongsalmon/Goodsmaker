# 라미아크릴 칼선 · 재단여백 매니저

브라우저에서 투명 이미지를 분석해 코롯토/아크릴과 스티커 대지용 출력 레이어를 만드는 정적 웹 앱입니다.

## 이번 버전의 주요 기능

- 코롯토/아크릴 모드와 다중 이미지 스티커 대지 모드
- 두 모드 모두 `무테` / `유테` 선택
  - 무테: 그림 외곽 칼선 + 인접 색상 기반 재단여백 확장
  - 유테: 그림 밖으로 입력한 투명 테두리만큼 오프셋한 칼선
- 그림 / 화이트 / 칼선 / 재단여백 확장 도안 개별 미리보기
- 다운로드에 포함할 레이어를 체크박스로 선택
- 칼선 단순화 슬라이더
- 내부 구멍 칼선 포함 여부
- 코롯토 밑바닥 직선 처리와 새 투명 바닥 영역의 색상 확장 제외
- 미리보기 배경: 투명 격자, 흰색, 회색, 검정색, 사용자 지정
- 완성 크기 기준 PPI 경고
- SVG 및 PDF 호환 `.ai` 내보내기

## 경계 색상 확장 방식

안티에일리어싱 끝 픽셀 하나의 색을 그대로 복제하지 않습니다.

1. 알파 마스크의 고립 픽셀과 작은 돌기를 정리합니다.
2. 외곽선의 접선/법선 방향을 주변 여러 픽셀로 계산합니다.
3. 외곽 안쪽 3–24px 범위에서 여러 색상 군집과 각 군집의 위치를 분석합니다.
4. 경계 가까이에 실제로 닿은 색을 우선하고, 더 안쪽의 다른 색이 좁은 팔·귀 등의 색을 덮어쓰지 않게 합니다.
5. 재단여백 영역에는 가장 알맞은 경계 색상 모델을 방향성 거리로 전파합니다. 이전처럼 주변 색을 계속 평균하지 않아 삼각형 모양의 잘못된 색 번짐을 줄였습니다.

이미지마다 구조가 다르므로 결과가 너무 단순하거나 세밀할 때는 `경계 색상 샘플 깊이`, `알파 임계값`, `칼선 단순화`를 조절하세요.

## 실행

별도 설치 없이 `index.html`을 열 수 있습니다. 브라우저의 로컬 파일 보안 정책으로 문제가 생기면 폴더에서 간단한 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

저장소 최상위에 다음 네 파일을 올립니다.

```text
index.html
style.css
app.js
README.md
```

저장소의 `Settings → Pages → Deploy from a branch → main → /(root)`를 선택합니다.

## Railway와 계산 속도

현재 이미지 계산은 서버가 아니라 사용자의 브라우저에서 실행됩니다. 따라서 같은 파일을 Railway에 정적 배포해도 초기 다운로드 위치만 바뀌며 칼선/재단여백 계산 자체는 거의 빨라지지 않습니다.

이번 버전에서는 스티커를 대지 전체 크기로 매번 계산하지 않고 각 스티커의 주변 영역만 처리하도록 변경해 스티커 모드의 불필요한 계산을 줄였습니다. 더 큰 성능 향상이 필요하면 다음 단계로 Web Worker 또는 WebAssembly/OpenCV 기반 처리 엔진을 붙이는 방식이 적합합니다.

## 내보내기 참고

- SVG는 선택한 레이어를 `WHITE`, `BLEED_EXTENSION`, `ARTWORK`, `CUTLINE` 그룹으로 분리합니다.
- `.ai`는 Illustrator에서 열 수 있는 PDF 1.4 호환 파일입니다. 선택한 래스터 레이어와 벡터 칼선을 포함하지만 Adobe의 비공개 네이티브 AI 구조는 아닙니다.
- 실제 제작 전 Illustrator에서 칼선 별색, 선 굵기, 오버프린트, CMYK/화이트 인쇄 설정을 확인하세요.
