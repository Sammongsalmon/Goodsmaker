# 아크릴 제작 매니저 👾 — v17

투명 이미지를 브라우저에서 분석해 아크릴·코롯토와 스티커용 **그림 / 화이트 / 재단여백 확장 / 칼선** 레이어를 만드는 정적 웹 앱입니다. 새로 추가된 **외곽선 / 배경 메이커**에서는 굿즈용 꾸밈 이미지와 배경도 제작할 수 있습니다.

이미지는 서버로 전송되지 않으며 계산과 자동 저장은 현재 브라우저에서 수행됩니다.

## v17에서 바뀐 내용

### 스티커 모바일 편집

- 선택한 개체의 네 모서리에 크기 조절 핸들, 위쪽에 회전 핸들을 표시합니다.
- 마우스와 터치에서 같은 Pointer Events 로직을 사용합니다.
- 모바일 브라우저의 스크롤·확대 제스처가 편집을 가로채지 않도록 작업 캔버스에 `touch-action: none`을 적용했습니다.
- 개체 본체 드래그: 이동
- 모서리 원 드래그: 비율을 유지하며 크기 조절
- 위쪽 회전 원 드래그: 회전
- 수치 입력으로도 가로 크기, 회전, X, Y를 직접 수정할 수 있습니다.

### 한 이미지 안의 개체 쪼개기

1. 투명 PNG 또는 WebP를 스티커 대지에 올립니다.
2. 쪼갤 이미지를 선택합니다.
3. `가까운 개체 연결 거리`를 슬라이더 또는 mm 수치로 조절합니다.
4. `쪼개진 칼선 미리보기`를 누릅니다.
5. 청록색 점선 결과를 확인한 뒤 `미리보기대로 쪼개기`를 누릅니다.

쪼개진 개체는 여러 이미지를 따로 올린 것처럼 각각 이동·회전·크기 조절·앞뒤 순서 변경이 가능합니다.

- `0 mm`: 완전히 떨어진 픽셀 덩어리마다 분리
- 값을 높임: 가까운 덩어리를 자연스러운 외곽선으로 연결해 하나로 묶음
- 아주 작은 먼지 픽셀은 개체로 만들지 않음
- 배경까지 불투명한 JPG·PNG는 개체 사이를 판별할 수 없으므로 투명 배경 파일이 필요함

### 여러 개체 선택과 칼선 합치기

- 데스크톱: 빈 대지를 드래그해 선택 영역으로 감싸거나 `Shift / Ctrl / Command`를 누른 채 개체 클릭
- 모바일: `다중 선택`을 켠 뒤 개체를 차례로 탭
- `선택 개체 합치기`: 선택한 여러 개체를 하나의 칼선 그룹으로 묶음
- `합치기 해제`: 다시 개별 칼선으로 분리
- 그룹으로 묶여도 원본 개체의 배치와 레이어 순서는 유지
- `칼선 새로고침 · 출력 다시 만들기`로 현재 배치와 그룹 상태를 최종 출력에 반영

### 스티커 대지와 배경

- 대지 가로·세로 직접 입력
- 비율 빠른 선택: `1:1`, `4:5`, `9:16`, `A4`
- 배경 종류:
  - 단색
  - 2색 선형 그라데이션과 각도
  - 배경 이미지
  - 반복 패턴
- 배경 이미지 배치:
  - 대지 채우기
  - 전체 보이기
  - 늘이기
  - 직접 설정: 확대율, X, Y
- 패턴:
  - 업로드 이미지 반복
  - 사각 그리드
  - 사선 그리드
  - 땡땡이
  - 줄무늬
  - 별
  - 하트
- 패턴 전경색·배경색, 크기, X, Y를 직접 조절
- 색상 입력은 누르면 바로 브라우저 컬러피커가 열리는 `color` 입력 사용

## 외곽선 / 배경 메이커

굿즈용 꾸밈 이미지, 프로필 카드, 스티커 배경, 썸네일 등을 만들기 위한 별도 탭입니다.

### 캔버스

- 여러 투명 이미지 추가
- 캔버스 가로·세로 직접 입력
- 비율 템플릿: `1:1`, `4:5`, `9:16`, `A4`
- 외부 칼선 여백 직접 입력

### 개체 편집

- 이동, 회전, 크기 조절
- 맨 뒤로 / 한 단계 뒤로 / 한 단계 앞으로 / 맨 앞으로
- 삭제
- 선택 개체마다 아래 효과를 개별 설정

### 외곽선과 효과

- 외곽선: 사용 여부, 색, 두께
- 외부광선: 색, 불투명도, 크기, 번짐
- 내부광선: 색, 불투명도, 크기, 번짐
- 그림자: 색, 불투명도, 크기, 번짐, X 위치, Y 위치
- 외곽선을 켠 경우 칼선은 외곽선까지 합친 최종 모양을 기준으로 생성
- 외곽선이 없으면 원본 개체 자체를 기준으로 칼선 생성

### 메이커 배경

스티커 배경과 같은 방식으로 단색, 그라데이션, 배경 이미지, 반복 패턴을 사용할 수 있습니다. 기본 패턴 템플릿과 업로드 패턴 모두 확대율과 위치 조절을 지원합니다.

## 기존 아크릴·코롯토 기능

- 대지 크기와 그림 크기 분리
- 그림 크기와 원본 대비 확대율 양방향 연동
- 무테 색상 재단여백 확장
- 유테 투명 테두리와 칼선
- 내부 빈 공간 칼선 포함 여부
- 무테·유테 밑바닥
- 밑바닥 빈 공간 유지 / 색상 채우기
- 밑바닥 범위와 모서리 둥글기
- 내부·외부 다중 타공
- 타공 중앙 정렬과 외부 타공 간격
- 실제 반투명 면이 있을 때만 화이트 레이어 2종 제공
- PNG / SVG / PDF 호환 AI 출력

## 미리보기와 다운로드

레이어별 미리보기를 지원하며 다운로드 체크박스로 포함 여부를 정할 수 있습니다.

- **PNG**: 선택한 레이어를 합성한 투명 PNG
- **SVG**: 배경, 화이트, 확장 도안, 그림, 칼선을 그룹으로 분리
- **AI**: Illustrator에서 열 수 있는 PDF 1.4 호환 `.ai`

AI 파일은 Adobe의 비공개 네이티브 AI 포맷이 아닙니다. 실제 제작 전 Illustrator에서 칼선 별색, 오버프린트, CMYK, 화이트 인쇄 설정을 확인하세요.

## 작업 자동 저장

- 업로드 이미지와 주요 편집 상태를 IndexedDB에 저장
- 같은 사이트 주소와 같은 브라우저에서 새로고침하면 복원
- 쪼개진 개체, 그룹, 배치, 회전, 크기, 메이커 효과와 배경도 복원
- 상단 `초기화`를 누르면 현재 탭 작업을 비움
- 시크릿 모드, 사이트 데이터 삭제, 배포 주소 변경 시 저장 내용이 사라질 수 있음

## 실행

다음 파일을 같은 폴더에 둡니다.

```text
index.html
style.css
app.js
README.md
```

`index.html`을 직접 열거나 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

저장소 최상위에 네 파일을 올린 뒤 다음을 선택합니다.

```text
Settings → Pages → Deploy from a branch → main → /(root)
```

기존 배포 파일을 교체한 뒤 이전 화면이 남아 있으면 강력 새로고침을 사용하세요.

- Windows: `Ctrl + Shift + R`
- macOS: `Command + Shift + R`

## 성능

색상 확장, 개체 분석, 거리 변환, 벡터화는 서버가 아니라 사용자 브라우저에서 실행됩니다. Railway로 정적 배포 위치만 옮겨도 계산 속도는 크게 달라지지 않습니다. 큰 이미지나 개체가 많은 대지에서는 배치 중 `빠른 편집`, 최종 출력 직전 `균형` 또는 `정밀 출력`을 권장합니다.
