# 라미아크릴 칼선 · 재단여백 매니저

투명 이미지를 브라우저에서 분석해 코롯토/아크릴과 스티커 대지용 출력 레이어를 만드는 정적 웹 앱입니다. 별도 서버 없이 `index.html`만으로 실행되며, GitHub Pages에도 그대로 배포할 수 있습니다.

## 주요 기능

### 코롯토 / 아크릴

- 무테: 그림 외곽 칼선과 인접 색상 기반 재단여백 확장
- 유테: 입력한 폭만큼 떨어진 외곽 칼선
- 내부 빈 공간 칼선 포함 여부
- 밑바닥 직선 추가
- 밑바닥과 도안 사이 처리 선택
  - `빈 공간 유지`: 새로 생긴 내부 공간을 투명하게 유지하고 그 구간 바깥에도 색상 확장을 만들지 않음
  - `색상 채우기`: 내부 공간과 바깥 재단여백을 주변 색상으로 연결
- 끝의 안티에일리어싱 한 픽셀이 아니라 안쪽 여러 픽셀과 경계 방향을 분석하는 색상 확장

### 스티커 대지

- 여러 투명 이미지 추가, 이동, 회전, 크기 변경
- 무테 색상 재단여백
- 유테 투명 처리 또는 화이트 채움
- 화이트 채움 선택 시 칼선 바깥 화이트 재단여백 설정
- 대지 전체 배경지 추가
  - 단색
  - 배경 이미지
  - 채우기 / 전체 보이기 / 늘이기
- 배경지는 별도 미리보기 및 별도 출력 레이어로 관리

### 칼선 품질

- 유클리드 거리 기반 원형 오프셋으로 위·옆 모서리의 각진 직선 돌출 감소
- `단순화`: 작은 픽셀 굴곡과 점 수를 줄이면서 주요 오목 꼭짓점 보존
- `부드럽게`: 꼭짓점을 둥글리고 SVG·AI 칼선을 cubic Bézier 곡선으로 출력
- 그림 / 배경지 / 화이트 / 칼선 / 무테 확장 도안 개별 미리보기
- 출력에 포함할 레이어 체크박스 선택

## 실행

파일을 같은 폴더에 둡니다.

```text
index.html
style.css
app.js
README.md
```

`index.html`을 브라우저에서 열면 됩니다. 브라우저의 로컬 파일 정책으로 문제가 생기면 폴더에서 다음을 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

저장소 최상위에 네 파일을 올린 뒤 다음을 선택합니다.

```text
Settings → Pages → Deploy from a branch → main → /(root)
```

## 성능 참고

계산은 서버가 아니라 사용자의 브라우저에서 실행됩니다. Railway에 정적 배포해도 계산 자체가 빨라지지는 않습니다. 이번 버전의 외곽 오프셋은 사각형 형태의 픽셀 팽창 대신 2차원 거리 변환을 사용해 더 둥근 결과를 만들며, 처리 품질에 따라 내부 작업 해상도를 제한합니다.

큰 이미지가 많을 때는 먼저 `빠른 편집`으로 배치하고, 최종 내보내기 전에 `균형` 또는 `정밀 출력`으로 다시 생성하는 방식을 권장합니다.

## 내보내기

- SVG: `BACKGROUND`, `WHITE`, `BLEED_EXTENSION`, `ARTWORK`, `CUTLINE` 그룹
- AI: Illustrator에서 열 수 있는 PDF 1.4 호환 `.ai`
- 칼선은 SVG와 AI 모두 Bézier 곡선 명령으로 출력

Adobe의 비공개 네이티브 AI 구조는 아니므로 실제 제작 전 Illustrator에서 칼선 별색, 선 굵기, 오버프린트, CMYK와 화이트 인쇄 설정을 확인하세요.
