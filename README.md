# 아크릴 제작 매니저 👾 v19

브라우저에서 아크릴·코롯토·스티커 제작용 칼선과 출력 레이어를 만들고, 외곽선·배경 이미지를 편집하는 정적 웹 앱입니다. 별도 서버 없이 `index.html`, `style.css`, `app.js`만으로 실행됩니다.

## v19 주요 변경 사항

### 스티커 개체 쪼개기와 수동 합치기

- **0 mm에서는 원본 이미지의 알파 픽셀 기준으로 완전히 떨어진 개체를 모두 분리**합니다.
- 연결 거리(threshold)는 칼선 여백이 아니라 **원본 개체 픽셀 사이의 실제 거리**를 기준으로 계산합니다.
- threshold 안의 개체는 곡선 연결부를 가진 하나의 미리보기 칼선으로 자동 묶입니다.
- 미리보기 칼선을 클릭하거나 드래그 선택해 여러 개를 고른 뒤 `선택 칼선 합치기`를 누르면, threshold보다 멀리 떨어져 있어도 수동으로 한 외곽선에 묶을 수 있습니다.
- 수동으로 묶은 개체는 최소 연결 경로를 이용해 자연스럽게 연결합니다.
- `미리보기 적용 · 칼선 새로고침`을 누르면 미리보기 상태가 실제 독립 스티커 개체와 최종 칼선에 반영됩니다.
- 쪼개진 개체는 각각 이동, 크기 조절, 회전, 앞뒤 순서 변경이 가능합니다.

### 정렬과 직접 편집

- 가로 중앙, 세로 중앙, 전체 중앙 정렬
- 칼선 기준 위·아래·왼쪽·오른쪽 정렬
- 여러 개체 선택 시 현재 간격을 유지한 묶음 정렬
- 모바일과 데스크톱에서 이동, 비율 유지 크기 조절, 회전 지원
- 숫자 입력창에 포커스할 때만 아래 슬라이더가 나타나며 숫자와 양방향으로 동기화

### 패턴 배경

스티커와 외곽선/배경 메이커에서 다음 기능을 지원합니다.

- 사각 그리드, 사선 그리드, 땡땡이, 줄무늬, 별, 하트, 업로드 이미지 패턴
- 그리드·줄무늬의 실선/점선과 선 굵기
- 입자 패턴의 크기, 간격, 사각·사선·랜덤 배치
- 패턴 배경을 단색 또는 그라데이션으로 설정
- 여러 패턴 이미지 동시 업로드 및 투명 여백 자동 제거
- **겹침 방지 균형 순환**: 이미지 개수와 서로소인 가장 작은 행 이동값을 사용해 바로 위·아래 줄에 같은 이미지가 반복되지 않도록 배치
- **자연스러운 랜덤 순서**: 업로드된 이미지 순서를 고정 난수로 섞어 같은 설정에서 안정적인 랜덤 패턴 생성
- 홀수 개 이미지도 행마다 자연스럽게 순환하도록 처리

### 컬러피커

앱의 모든 색상 입력은 자체 컬러피커를 사용합니다.

- 채도·밝기 2차원 선택 영역
- 실제 이동할 색이 보이는 무지개 Hue 바
- 현재 색의 투명 변화를 보여 주는 알파 바
- 슬라이더 손잡이는 흰색 원으로 표시
- 청록색 진행 채움 효과 제거
- 8자리 HEX와 투명도 지원

### 외곽선 / 배경 메이커

이 탭은 제작용 칼선·화이트 추출 없이 일반 이미지를 만드는 편집기입니다.

- 업로드 이미지의 투명 여백을 자동 제거한 뒤 실제 정보가 있는 영역만 배치
- 이동, 회전, 크기 변경, 앞뒤 순서 조절
- 외곽선, 외부광선, 내부광선, 그림자 효과
- 선택 개체의 효과 설정을 다른 모든 개체에 일괄 적용
- 외곽선은 알파 마스크를 곡선 경로로 보간하고 라운드 처리와 안티에일리어싱을 적용해 계단 현상 완화
- 투명·단색·그라데이션·이미지·패턴 배경
- PNG와 JPG만 저장
- PNG 저장 시 투명 배경 또는 흰 배경 선택

### 내보내기 파일 이름

상단의 `파일 이름` 입력란에 원하는 이름을 입력하면 해당 이름으로 저장됩니다. 비워 두면 모드에 맞는 기본 이름을 사용합니다. 확장자는 자동으로 붙습니다.

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열 수 있습니다. 브라우저의 로컬 파일 보안 정책으로 작업 저장 복원이 제한되면 GitHub Pages 같은 정적 호스팅에 올려 사용하세요.

## GitHub Pages 배포

1. 저장소 최상위에 다음 파일을 업로드합니다.

   ```text
   index.html
   style.css
   app.js
   README.md
   ```

2. `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.
5. 배포가 완료되면 Pages 화면의 `Visit site`에서 주소를 확인합니다.

기존 저장소를 업데이트할 때는 네 파일을 모두 덮어써야 합니다. 이전 코드가 남아 보이면 강력 새로고침을 사용하세요.

- Windows: `Ctrl + Shift + R`
- macOS: `Command + Shift + R`

## 작업 저장

편집 중인 이미지와 설정은 같은 브라우저·같은 배포 주소의 IndexedDB에 저장됩니다. 새로고침 후에도 복원되며 `초기화`를 누르면 현재 모드의 작업이 비워집니다. 시크릿 모드, 브라우저 데이터 삭제, 배포 도메인 변경 시 저장 내용이 사라질 수 있습니다.

## 출력 형식

- 아크릴/코롯토·스티커: 선택 레이어 PNG, SVG, PDF 1.4 호환 `.ai`
- 외곽선/배경 메이커: PNG, JPG

`.ai`는 Adobe Illustrator의 비공개 네이티브 구조가 아니라 Illustrator에서 열 수 있는 PDF 호환 파일입니다. 실제 발주 전 제작 업체의 별색, 오버프린트, CMYK, 타공 규격을 확인하세요.
