# 아크릴 제작 매니저 👾 v18

브라우저에서 아크릴·코롯토·스티커 제작용 칼선과 출력 레이어를 만들고, 간단한 외곽선·배경 이미지를 편집하는 정적 웹 앱입니다. 별도 서버 없이 `index.html`, `style.css`, `app.js`만으로 실행됩니다.

## v18 주요 변경 사항

### 스티커 개체 쪼개기

- **0 mm에서는 투명 픽셀 기준으로 완전히 떨어진 모든 개체를 각각 분리**합니다.
- 연결 거리(threshold)는 칼선 사이가 아니라 **원본 개체의 실제 픽셀 외곽 사이 거리**로 계산합니다.
- 값을 높이면 해당 거리 안의 개체를 자연스러운 곡선으로 연결해 한 칼선으로 묶습니다.
- 미리보기 확인 후 `미리보기대로 쪼개기`를 누르면 각 개체가 독립 이미지처럼 바뀝니다.
- 쪼개진 개체는 각각 이동, 크기 조절, 회전, 앞뒤 순서 변경이 가능합니다.
- 빈 대지를 드래그하거나 다중 선택을 켜 여러 개체를 선택한 뒤 하나의 칼선으로 합치거나 다시 해제할 수 있습니다.

### 개체 정렬

스티커와 외곽선/배경 메이커의 선택 편집 영역에 다음 정렬 버튼이 추가되었습니다.

- 가로 중앙
- 세로 중앙
- 대지 정중앙
- 외곽 기준 위·아래·왼쪽·오른쪽 정렬

스티커에서 여러 개체를 선택하면 현재 간격을 유지한 채 묶음 전체가 정렬됩니다.

### 모바일·데스크톱 직접 편집

- 개체 내부 드래그: 이동
- 모서리 원형 손잡이: 비율 유지 크기 조절
- 위쪽 회전 손잡이: 회전
- 터치 환경에서는 손잡이와 판정 범위를 더 크게 표시합니다.
- 캔버스 편집 중 브라우저 스크롤 제스처가 끼어들지 않도록 포인터 입력을 분리했습니다.

### 배경 및 패턴

스티커 배경과 외곽선/배경 메이커 모두 다음 배경을 지원합니다.

- 투명, 단색, 그라데이션, 배경 이미지, 패턴
- 사각 그리드, 사선 그리드, 땡땡이, 줄무늬, 별, 하트
- 그리드·줄무늬: 실선/점선, 선 굵기
- 입자 패턴: 크기, 간격, 사각 배열, 사선 배열, 랜덤 배열
- 업로드 이미지 패턴: 여러 파일을 한 번에 업로드해 모두 사용
- 각 패턴 파일의 투명 여백을 자동 제거한 뒤 실제 그림 부분만 입자로 사용
- 홀수 개 이미지도 행마다 순서를 바꾸어 자연스럽게 섞음
- 랜덤 배치는 같은 설정에서 결과가 흔들리지 않는 고정 난수 방식 사용
- 업로드 이미지 패턴에도 별·하트 패턴과 같은 크기, 간격, 배열, 배경색 설정 적용

### 색상 선택기

브라우저 기본 색상 창 대신 앱 내부 컬러피커를 사용합니다.

- 채도·밝기 2차원 영역
- 색상(Hue) 슬라이더
- 투명도 슬라이더
- 8자리 HEX 직접 입력
- 현재 색과 투명도 즉시 미리보기

앱에서 사용하는 모든 색상 입력에 동일하게 적용됩니다.

### 숫자 입력 슬라이더

크기, 확대율, X/Y 위치, 회전, 효과 크기 등 모든 숫자 입력은 다음 방식으로 동작합니다.

- 평소에는 숫자 입력창만 표시
- 입력창을 클릭해 포커스하면 바로 아래에 슬라이더 표시
- 숫자 입력과 슬라이더 값이 양방향으로 동기화
- 음수 위치나 회전값도 해당 입력 범위에 맞게 조절

### 외곽선 / 배경 메이커

이 탭은 제작용 칼선·화이트 추출이 아니라 보기 좋은 일반 이미지를 만드는 전용 편집기로 정리했습니다.

- 이미지 이동, 크기 조절, 회전, 앞뒤 순서
- 단색 외곽선
- 외부광선, 내부광선, 그림자
- 투명·단색·그라데이션·이미지·패턴 배경
- 제작 레이어와 칼선 관련 옵션은 표시하지 않음
- **PNG와 JPG만 저장**
- PNG: 투명 배경 또는 흰 배경 선택
- JPG: 형식 특성상 흰 배경으로 저장

## 실행 방법

압축을 푼 뒤 `index.html`을 브라우저에서 열 수 있습니다. 일부 브라우저의 로컬 파일 보안 정책으로 저장 복원이 제한되면 GitHub Pages 같은 정적 호스팅에 올려 사용하세요.

## GitHub Pages 배포

1. 저장소 최상위에 다음 파일을 업로드합니다.

   ```text
   index.html
   style.css
   app.js
   README.md
   ```

2. 저장소의 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/(root)`로 지정하고 저장합니다.
5. 배포 완료 후 Pages 화면의 `Visit site`에서 주소를 확인합니다.

기존 저장소를 업데이트할 때는 네 파일을 모두 덮어써야 합니다. 배포 후 이전 화면이 남으면 강력 새로고침을 사용하세요.

- Windows: `Ctrl + Shift + R`
- macOS: `Command + Shift + R`

## 작업 저장

편집 중인 이미지와 설정은 같은 브라우저·같은 배포 주소의 IndexedDB에 저장됩니다. 새로고침 후에도 복원되며 `초기화`를 누르면 현재 모드의 작업이 비워집니다. 시크릿 모드, 브라우저 데이터 삭제, 배포 도메인 변경 시 저장 내용이 사라질 수 있습니다.

## 출력 형식

- 아크릴/코롯토·스티커: 선택 레이어 PNG, SVG, PDF 1.4 호환 `.ai`
- 외곽선/배경 메이커: PNG, JPG

`.ai`는 Adobe Illustrator의 비공개 네이티브 구조가 아니라 Illustrator에서 열 수 있는 PDF 호환 파일입니다. 실제 발주 전 제작 업체의 별색, 오버프린트, CMYK, 타공 규격을 확인하세요.
