# 라미아크릴 칼선 · 재단여백 매니저

브라우저에서 바로 실행하는 정적 웹 프로토타입입니다. 빌드 도구나 외부 라이브러리가 필요하지 않습니다.

## 실행

가장 안정적인 방법은 폴더에서 로컬 서버를 여는 것입니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요. 단순히 `index.html`을 더블클릭해도 업로드한 파일은 동작하지만, 포함된 샘플 이미지는 브라우저 보안 정책에 따라 표시되지 않을 수 있습니다.

## 구현된 기능

- 코롯토 / 아크릴 모드
  - 투명 이미지 알파 외곽선 자동 추적
  - 내부 구멍 칼선 포함 여부 선택
  - 내부 구멍 칼선을 끄면 안쪽 공간은 재단여백 색을 채우지 않음
  - 재단여백 mm 입력 및 외곽 색 자동 확장
  - 밑바닥 추가: 가장 낮은 좌·우 지점을 직선으로 연결
  - 새로 생긴 투명 밑바닥 영역에는 인쇄색과 넘침 색을 만들지 않음
  - 완성 크기 대비 유효 PPI 경고
- 스티커 대지 모드
  - 대지 크기 입력
  - 여러 투명 이미지 업로드
  - 캔버스에서 드래그 배치
  - 선택 이미지의 가로 크기, X/Y, 회전 입력
  - 흰 스티커 테두리와 바깥 재단여백 자동 생성
- 보기
  - 전체 / 원본 / 재단여백 / 칼선 분리 미리보기
  - 확대, 축소, 맞춤
- 내보내기
  - SVG: `ORIGINAL_ARTWORK`, `PRINT_WITH_BLEED`, `CUTLINE` 그룹
  - AI: PDF 1.4 호환 `.ai` 파일. 인쇄층은 투명 래스터, 칼선은 벡터 패스로 저장

## 알고리즘 메모

1. 알파 임계값으로 인쇄 영역 마스크를 만듭니다.
2. 픽셀 셀의 방향성 경계를 연결해 닫힌 칼선 패스를 얻고 Ramer–Douglas–Peucker 방식으로 단순화합니다.
3. 외곽 패스와 내부 구멍 패스를 방향으로 분리합니다.
4. 재단여백은 칼선 바깥의 허용 영역에서 가장 가까운 인쇄 경계색을 다중 시작점 방식으로 전파합니다.
5. 밑바닥을 켜면 하단 굴곡 구간을 직선으로 바꾸고, 직선 안쪽의 새 투명 면과 그 아래 대응 영역을 색 전파 대상에서 제외합니다.
6. 스티커는 각 배치 이미지의 알파 마스크를 테두리 폭만큼 팽창시켜 흰 테두리와 칼선을 만듭니다.

## 제작용으로 고도화할 때 권장하는 항목

- 곡선 Bézier 피팅과 스무딩 강도 조절
- 색 경계의 접선 추정 및 방향성 인페인팅
- 겹친 스티커의 개별 칼선 / 합쳐진 칼선 선택
- CMYK, 별색 칼선, 오버프린트, ICC 프로파일
- 실제 Illustrator 네이티브 레이어 데이터와 패키징
- Web Worker / WASM 기반 대용량 이미지 가속

이 프로토타입의 AI 파일은 Illustrator가 열 수 있는 PDF 호환 구조이며, Adobe 전용 네이티브 AI 편집 데이터를 복제한 형식은 아닙니다.
