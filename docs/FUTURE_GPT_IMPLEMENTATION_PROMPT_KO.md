# 미래 구현용 GPT 시작 프롬프트

아래 내용을 새 웹 편집기 제작 요청의 앞부분에 붙여 사용할 수 있습니다.

---

당신은 고급 웹 기반 이미지·캔버스 편집기를 설계하고 구현한다. 기능을 곧바로 DOM에 덧붙이지 말고, 먼저 상태 모델·선택 상태 머신·렌더 파이프라인·저장 형식·실행취소 작업 단위를 설계한다.

## 필수 설계 원칙

1. 원본 이미지/알파/개체 관계를 진실의 원천으로 유지하고, 미리보기·효과·외곽선·출력물은 파생 데이터로 둔다.
2. 이동·회전·크기 조절 중에는 가벼운 가이드만 갱신하고 고비용 연산은 pointerup, idle, 또는 명시적 다시 만들기에서 실행한다.
3. Pointer Events와 pointer capture로 모바일·데스크톱을 함께 지원한다.
4. 단일 선택, 다중 선택, 드래그 선택, 그룹, 그룹 내부 개별 편집, z-order를 처음부터 데이터 모델에 포함한다.
5. 그룹의 외곽선·광선·그림자는 구성원을 먼저 합성한 union alpha 기준으로 한 번만 적용한다.
6. 실행취소/재실행, IndexedDB 작업 복원, schema migration을 기반 기능으로 넣는다.
7. 모든 숫자 입력에는 단위·범위·clamp를 두고, 포커스할 때만 아래에 슬라이더를 표시하며 숫자와 양방향 동기화한다.
8. 컬러피커는 채도/명도 영역, 실제 무지개 Hue 바, 현재 색의 alpha 바, 흰색 원형 손잡이, HEX 8자리 입력을 제공한다.
9. 업로드한 꾸밀 개체와 패턴 이미지는 투명 여백을 먼저 자른다.
10. 랜덤 패턴은 seed 기반 결정적 난수를 사용해 같은 설정에서 배치가 흔들리지 않게 한다.
11. 미리보기와 내보내기는 동일한 렌더 파이프라인을 사용하고 해상도만 다르게 한다.
12. SVG 비트맵은 data URI로 임베드하고 `href`와 `xlink:href`, `xmlns:xlink`, SVG 1.1을 함께 사용해 Illustrator 호환성을 검사한다.

## UI 기본값

- 전체 UI는 편안한 저채도 색, 투명 체크무늬는 중립 회색.
- 의미 없는 옵션은 숨긴다. 데이터가 실제 반투명 면을 포함할 때만 반투명 전용 옵션을 표시한다.
- 같은 주제의 옵션은 한 카드에 평평하게 배치하고 불필요한 중첩 카드는 만들지 않는다.
- 결과와 다음 행동이 이해되는 설명을 사용하고 알고리즘 용어를 그대로 노출하지 않는다.
- 사용자 파일명 입력을 지원하고 비어 있으면 안전한 기본 파일명을 쓴다.

## 성능

- dirty flag와 캐시를 단계별로 둔다.
- preview 해상도와 export 해상도를 분리한다.
- 픽셀 분석은 Web Worker/OffscreenCanvas 사용을 우선 검토한다.
- 작업 취소 token을 사용한다.
- 서버 배포만으로 클라이언트 연산이 빨라진다고 가정하지 않는다.

## 완료 전 필수 테스트

- 모바일 이동/회전/크기 조절
- 클릭 및 드래그 다중 선택
- 그룹 효과가 내부 경계에 침범하지 않는지
- 새로고침 복원과 이전 schema migration
- deterministic pattern
- 투명/흰 배경 PNG와 JPG
- 브라우저와 Illustrator에서 SVG 재열기
- 작은 AA 픽셀, 실제 반투명 면, 단색, 그라데이션, 대지 경계 인접 이미지를 포함한 골든 이미지 테스트

구현 전에 데이터 구조, 상태 전이, 렌더 단계, 캐시 무효화 규칙, 테스트 계획을 먼저 제시하고 그 설계에 맞춰 코드를 작성한다.
